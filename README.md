# Contact Form with JavaScript Validation

## Objective
This project is a Contact Form with client-side validation using HTML, CSS, and JavaScript.

## Features
- Name validation
- Email validation using Regex
- Message validation
- Error messages for invalid inputs
- Success message on valid submission
- Prevents form submission if inputs are invalid

## Technologies Used
- HTML
- CSS
- JavaScript

## Files
- index.html → Structure of the contact form
- style.css → Styling of the form
- script.js → Validation logic

## Validation Rules
1. Name field cannot be empty.
2. Email field must contain a valid email address.
3. Message field cannot be empty.
4. Error messages are displayed below the respective fields.
5. Success message is shown when all inputs are valid.

## How to Run
1. Download the project files.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser or use Live Server.
4. Test the form with valid and invalid inputs.
